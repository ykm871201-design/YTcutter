# YT Cutter — 유튜브 영상 다운로드 & 구간 컷 편집기

유튜브 링크로 영상을 내려받고, 앱 안에서 미리 보며 원하는 구간을 잘라 저장하는 Windows용 한국어 프로그램입니다.
(Python + PySide6 + yt-dlp + FFmpeg)

> ⚠ **본인이 소유했거나 다운로드·편집 권한이 있는 영상에만 사용하세요.**
> DRM·유료·멤버십·로그인 필요 콘텐츠 등 보호 장치를 우회하는 기능은 없습니다.
> YouTube 약관과 저작권법 준수 책임은 사용자에게 있습니다.

## 1. 주요 기능

**다운로드**
- URL 검사 (youtube.com / youtu.be / shorts / live / m.youtube 등). 재생목록이 붙은 링크는 **그 영상 하나만** 받습니다. 재생목록 전용 링크는 첫 번째 영상만 받습니다.
- 썸네일·제목·채널·재생 시간 표시, 받을 수 있는 해상도 목록에서 화질 선택
- 영상+음성 스트림을 따로 받아 FFmpeg 로 **자동 병합** → MP4
- "호환성 우선" 옵션(기본 켜짐): H.264 + AAC 를 우선 선택 (유튜브 H.264는 최대 1080p)
- 진행률 · 속도 · 남은 시간 표시, **취소**(임시 폴더 자동 삭제)
- 비공개·삭제·연령 제한·멤버십·지역 제한·네트워크 오류 등을 한국어로 안내 + [자세히 보기]에 원본 로그
- **[설정 > yt-dlp 업데이트]**: 유튜브가 바뀌어 다운로드가 막히면 버튼 한 번으로 yt-dlp 를 최신 버전으로 (exe 에서도 동작, 프로그램을 다시 시작하면 적용)

**컷 편집**
- 다운로드한 영상이 자동으로 열림, 또는 **로컬 영상 열기**(mp4/mkv/webm/mov 등)
- 재생·일시정지, 탐색 슬라이더, ±0.1초/±5초 이동, 현재 시간 표시
- 현재 위치를 시작/종료점으로 지정하거나 `HH:MM:SS.mmm` 으로 직접 입력 (`MM:SS`, `초` 도 가능)
- 구간 길이 표시, **구간 미리보기**(시작점부터 재생해 종료점에서 멈춤)
- `0 ≤ 시작 < 종료 ≤ 영상 길이` 검증 (잘못되면 빨간 표시 + 안내)
- 여러 구간을 목록에 등록해 **각각 별도 파일**로 저장, 구간마다 이름 지정 가능
- 원본 파일은 절대 수정하지 않음. 같은 이름이 있으면 `이름 (1).mp4` 처럼 **자동으로 새 이름** (덮어쓰기 없음)

**저장 모드**

| 모드 | 방식 | 장점 | 주의 |
|---|---|---|---|
| **정확한 컷** (기본) | 재인코딩 → MP4 (H.264 + AAC) | 지정한 프레임부터 정확히 시작, 어디서나 재생 | 영상 길이만큼 시간이 걸림 |
| **빠른 컷** | 스트림 복사 (`-c copy`) | 몇 초 만에 완료, 화질 손실 없음 | 키프레임 때문에 **시작점이 앞당겨질 수 있음**. 원본이 VP9/Opus 면 WEBM, 그 밖의 비호환 코덱은 MKV 로 저장(화면에 안내) |

**음원만 추출**

- **[영상 전체 음원 추출]** 버튼: 구간을 지정하지 않아도 영상 전체의 소리를 한 번에 뽑습니다 (기본 MP3)
- 일부 구간만 뽑으려면 오른쪽 **[형식]**을 음원으로 바꾸고 평소처럼 구간 저장 — 여러 구간도 각각 별도 음원 파일로 저장
- 영상 파일은 그대로 두고 소리만 복사하므로 원본은 바뀌지 않음
- 소리가 없는 영상은 버튼이 꺼지고 그 이유를 안내

| 형식 | 특징 |
|---|---|
| **음원 MP3** | 어디서나 재생되는 가장 무난한 형식 (VBR, 약 190kbps) |
| **음원 M4A (AAC)** | 같은 용량에서 MP3 보다 음질이 좋음 (192kbps) |
| **음원 WAV (무손실)** | 음질 손실 없음, 용량이 매우 큼 (음악 편집용) |
| **음원 원본 그대로** | 변환하지 않고 소리만 그대로 복사 → 가장 빠르고 음질 손실 없음. 확장자는 원본 코덱에 맞춰 자동 선택 (AAC→M4A, Opus→OPUS, Vorbis→OGG 등) |

> 저장 모드(정확한 컷 / 빠른 컷)는 영상 저장에만 적용됩니다. 음원은 어느 형식이든 지정한 시점에 맞춰 추출됩니다.

## 3. 설치와 실행 (Windows 10/11)

### 3-1. Python 설치
[python.org](https://www.python.org/downloads/windows/) 에서 **Python 3.12**(3.10~3.13 가능) 설치. 설치 화면에서 **"Add python.exe to PATH"** 체크.

### 3-2. FFmpeg 준비 (필수)
병합·컷·영상 분석에 `ffmpeg.exe` 와 `ffprobe.exe` 가 필요합니다. 셋 중 하나를 고르세요.

1. **winget (가장 간단)** — 명령 프롬프트에서
   ```bat
   winget install Gyan.FFmpeg
   ```
   설치 후 프로그램(과 명령 프롬프트)을 다시 여세요.
2. **프로그램 폴더에 넣기** — https://www.gyan.dev/ffmpeg/builds/ 에서 `ffmpeg-release-essentials.zip` 을 받아 압축을 풀고,
   `bin` 안의 `ffmpeg.exe`, `ffprobe.exe` 를 `ytcutter\ffmpeg\` 폴더(직접 만들기)에 복사.
3. **직접 지정** — 앱의 [설정 > FFmpeg 위치 지정...] 에서 `ffmpeg.exe` 선택 (같은 폴더에 `ffprobe.exe` 필요)

앱은 `사용자 지정 경로 → 프로그램 폴더(ffmpeg\bin, ffmpeg, 루트) → PATH` 순서로 찾습니다. 없으면 실행 중 해결 방법을 안내합니다.

### 3-3. Deno 설치 (권장)
최신 yt-dlp 는 유튜브 처리에 JavaScript 런타임이 필요합니다. 없으면 일부 화질이 안 보이거나 다운로드가 실패할 수 있습니다.
```bat
winget install DenoLand.Deno
```
또는 `deno.exe` 를 프로그램 폴더에 넣으면 자동으로 사용합니다. (Node.js 가 설치되어 있으면 그것도 사용)

### 3-4. 실행
**방법 A — 더블클릭:** `run.bat` (처음 한 번은 가상환경을 만들고 패키지를 설치하느라 1~3분 걸림)

**방법 B — 명령어:**
```bat
cd ytcutter
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 4. 사용 방법

1. 유튜브 주소를 붙여넣고 **[영상 정보 가져오기]** (또는 Enter)
2. 왼쪽에서 썸네일·제목·채널·길이 확인 → URL 아래 **화질** 선택 (기본: 1080p 이하 최고 화질)
3. 오른쪽 아래 **저장 폴더** 확인 → URL 아래 **[다운로드]**. 진행률·속도·남은 시간 표시, **[취소]** 가능
4. 완료되면 영상이 가운데 플레이어에 자동으로 열립니다
5. 재생하며 시작·종료 줄의 **[현재 위치로]** 버튼(I / O) 또는 시간을 직접 입력 ([이동]은 그 지점으로 플레이어 이동)
6. **[구간 미리보기]** 로 확인
7. 저장
   - 하나만: **[선택 구간 저장]**
   - 여러 개: **[구간 추가]** 를 반복한 뒤 **[목록 전체 저장]**
   - 음원만: 오른쪽 **[형식]** 을 음원으로 바꾼 뒤 위와 동일 (영상 전체는 **[영상 전체 음원 추출]** 한 번)
8. 완료 창에서 **[결과 파일 열기]** / **[폴더 열기]**

**단축키** (영상 화면이나 구간 표를 한 번 클릭한 뒤)

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| Space | 재생/일시정지 | ← / → | 5초 이동 |
| I / O | 현재 위치를 시작/종료점으로 | , / . | 0.1초 이동 |
| P | 구간 미리보기 | Enter | 구간 추가 |
| Delete | 선택한 구간 삭제 | Ctrl+O | 로컬 영상 열기 |

**저장 파일 이름:** `원본이름_번호_시작-종료.mp4` (예: `여행 영상_01_000013.500-000020.000.mp4`), 구간 이름을 적으면 `원본이름_02_하이라이트.mp4`
영상 전체를 한 파일로 저장할 때(특히 음원 추출)는 `원본이름.mp3` 처럼 단순하게 저장됩니다. 같은 이름이 있으면 `원본이름 (1).mp3` 로 자동 변경합니다.

## 5. Windows 실행 파일(.exe) 만들기

```bat
build.bat
```
- PyInstaller **onedir** 방식으로 `dist\YTCutter\YTCutter.exe` 를 만듭니다 (Qt DLL 이 분리되어 LGPL 요건 충족에 유리).
- `ytcutter\ffmpeg\` 폴더와 `deno.exe` 가 있으면 자동으로 함께 복사합니다. (`deno.exe` 를 넣으면 라이선스 고지 `deno-LICENSE.md` 도 함께 복사)
- 배포할 때는 `dist\YTCutter` 폴더 전체를 압축해서 전달하세요. **THIRD_PARTY_NOTICES.md** 와 FFmpeg 라이선스 고지를 꼭 포함하세요.

수동 명령:
```bat
pip install -r requirements-dev.txt
pyinstaller --noconfirm --clean --windowed --name YTCutter --collect-all yt_dlp_ejs main.py
xcopy ffmpeg dist\YTCutter\ffmpeg\ /E /I /Y
```
> 백신 프로그램이 새로 빌드한 exe 를 오탐지하는 경우가 있습니다. 필요하면 예외 등록하세요.

## 6. 문제 해결

| 증상 | 원인·해결 |
|---|---|
| "FFmpeg를 찾을 수 없습니다" | 3-2절 방법으로 준비. winget 설치 직후라면 앱을 다시 실행 |
| "유튜브가 자동화 요청으로 판단해 차단" / 403 오류 / 화질 목록이 비정상적으로 적음 | **[설정 > yt-dlp 업데이트]** 실행 후 프로그램 다시 시작. Deno 설치 확인. 잠시 후 재시도 |
| "비공개 영상입니다" / "삭제되었거나 볼 수 없는 영상" | 공개 상태 확인. 로그인이 필요한 영상은 지원하지 않음 |
| "연령 제한" / "멤버십 전용" | 로그인·권한이 필요한 콘텐츠는 지원하지 않음 |
| `CERTIFICATE_VERIFY_FAILED` / `EE certificate key too weak` / "보안 연결(SSL 인증서) 확인에 실패" | 학교·회사 **보안 장비가 HTTPS를 검사**하면서 약한 키의 인증서를 쓰기 때문. [설정 > **네트워크 호환 모드**]를 켜고 다시 시도 (오류가 나면 앱이 먼저 물어봄). Windows 인증서 저장소를 사용하고 약한 키를 허용하며, 인증서 검증은 유지함. 그래도 안 되면 집·휴대폰 핫스팟 등 다른 네트워크에서 시도하거나 전산 담당자에게 youtube.com·googlevideo.com 검사 예외를 요청 |
| "네트워크에 연결할 수 없습니다" | 인터넷·방화벽·회사/학교 프록시 확인 |
| 1080p 보다 높은 화질을 골랐는데 VP9/AV1 으로 받아짐 | 유튜브 H.264 는 1080p 까지만 제공. 편집 후 정확한 컷으로 저장하면 MP4(H.264)가 됨 |
| 빠른 컷 결과의 시작이 지정보다 빠름 | 정상 동작(키프레임 단위). 정확히 자르려면 **정확한 컷** |
| 빠른 컷 결과가 .webm / .mkv | 원본 코덱이 MP4 와 맞지 않아서임(화면에 안내). MP4 가 필요하면 정확한 컷 |
| 화면이 잘리거나 버튼이 안 보임 | 창 크기는 모니터에 맞춰 자동 조정되며, 좌·우 패널은 공간이 부족하면 스크롤됨. 가운데·아래 경계선을 끌어 크기 조절 가능. 최소 권장 해상도: 1366×768(125%) / 1920×1080(150%) |
| 플레이어에 영상이 안 나오거나 소리만 남 | 그래픽 드라이버 업데이트. 파일 자체는 컷 가능(길이는 ffprobe 로 확인) |
| "저장 폴더에 쓸 권한이 없습니다" | 바탕화면/동영상 등 사용자 폴더 선택 (Program Files 불가) |
| 오류의 자세한 원인 | 오류 창의 [자세히 보기], 아래 로그 패널, [설정 > 로그 파일 열기] (`%APPDATA%\YTCutter\logs\app.log`) |

## 7. 구현 메모

- 다운로드·분석·인코딩은 모두 `QThread` 에서 실행 → UI 멈춤 없음. 작업 중 쓰면 안 되는 버튼은 비활성화.
- 외부 프로그램은 **인수 리스트**로 실행(`shell=False`) → URL·경로가 셸 명령으로 해석되지 않음. Windows 에서는 콘솔 창이 뜨지 않게 실행.
- 다운로드는 저장 폴더 안의 임시 폴더(`.ytcutter_tmp_xxxx`)에서 진행 후 완료 시 최종 이름으로 이동, 취소·실패 시 임시 폴더 삭제.
  병합 단계(보통 수 초) 중 취소하면 병합이 끝난 직후 정리됩니다.
- 컷은 `이름.part.mp4` 로 쓰고 성공 시 최종 이름으로 변경. 취소하면 FFmpeg 프로세스를 종료하고 작성 중 파일 삭제.
- 정확한 컷: `ffmpeg -ss 시작 -i 원본 -t 길이 -c:v libx264 -crf 20 -preset veryfast -c:a aac -b:a 192k -movflags +faststart`
  (설정 파일의 `crf`, `preset` 으로 조정 가능)
- 빠른 컷: `ffmpeg -ss 시작 -i 원본 -t 길이 -c copy -avoid_negative_ts make_zero`

pip install -r requirements-dev.txt
